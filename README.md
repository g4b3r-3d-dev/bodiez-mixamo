# Bodiez Local

Aplicação web local para personalização de personagens 3D com Blender como motor de processamento e suporte progressivo a esqueletos Mixamo.

## Estado

- Etapa 1: conexão local com Blender
- Etapa 2: importação, inspeção e visualização FBX/GLB/GLTF

O frontend usa React, TypeScript e Three.js. O backend local usa Python/FastAPI e executa scripts internos via Blender/bpy.
